# TenantGuard Roadmap

## v1.0 (Target: April 2025)
- Core specification
- Go reference implementation
- Java and Python bindings
- Schema-based and Row-Level isolation
- W3C Trace Context propagation
- AuditForge integration (TenantEvent publishing)
- Full documentation + ADRs
- Public launch

## v1.1 (Q2 2025)
- TypeScript / Node.js implementation
- Advanced isolation adapters (Document stores, Kafka, etc.)
- Policy engine basics
- Improved observability hooks

## v2.0 (Q4 2025)
- Enterprise Control Plane
- Automated tenant onboarding
- Compliance reporting dashboard (part of AuditForge enterprise)
- Self-hosted enterprise edition

## Long-term Vision
Become the de-facto multitenancy layer for regulated financial systems in Africa.
