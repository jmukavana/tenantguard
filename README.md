**Built for East Africa’s regulated fintech, banking, insurance, SACCOs, and government platforms.**

TenantGuard provides secure tenant isolation, context propagation, and seamless integration with regulatory-grade audit systems (AuditForge). It was extracted from real production experience building the CIC InsureMaster bancassurance platform.

## Why TenantGuard

- Secure by default (prevents tenant hopping)
- Regulatory-first (CBK, IRA, Data Protection Act)
- Platform agnostic (Java, Go, Python, TypeScript)
- Automatic audit event publishing to AuditForge
- Open Core – free forever for the multitenancy layer
